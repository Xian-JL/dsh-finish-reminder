# 0.2.0 交付说明

日期：2026-11-13。本版只实现用户选定的通知中心、静默、任务上下文三项更新，保留已验收基线交互。

## 使用位置

DSH设置 → 对话结束提醒 → 通知中心/静默设置/运行设置。没有新增快捷键或全局跳转入口。工作区选项用于筛选记录，不设置分工作区提醒策略；每条结束仍独立保存，不合并。

## 默认与数据

升级默认静默关闭，旧的显式启停配置保留。临时静默跨重启保存；排程默认每天22:00—08:00但不开启。旧schema=1记录直接兼容，工作区、历时缺失时保持未知。历史限制为500条已查看/已退休记录，未查看与活动卡片不受清理。

## 交付文件

artifacts/dsh-finish-reminder-0.2.0.tgz为预构建安装包，同名.sha256为校验值；版本收据和verification-summary记录源码绑定及开发检查。源工程保留design-v0.2.0.md、测试和本版人工验收清单。

## 验证边界

开发检查包括业务/协议、静默日历边界、中心筛选与分页、旧状态兼容、历史清理保护、上下文计算、组件静态渲染、x64原生编译、实际Cordis受控加载及确切包解包加载。真机新增界面、静默到点和新上下文的完整验收留给用户，不覆盖原有用户验收结论。

本次构建没有替换本机已安装的0.1.0，也没有改动真实Profile。升级步骤见README与MANUAL-ACCEPTANCE。
