# 0.2.0 增量规格与实现设计

日期：2026-11-13。基线为用户已验收的0.1.0当前实现，包含现有悬停暂停、导航在途保留卡片、失败原位反馈及现有视觉尺寸；不以初版spec中的历史交互描述回退这些行为。

## 本版范围

实现通知中心、免打扰/定时静默、任务上下文补充。不提供按会话或工作区调整提醒方式，不增加快捷键/下一条未查看跳转，也不合并同一会话的多次结束。通知中心的工作区条件只是查看筛选，不是提醒策略。

## 通知中心

入口位于既有插件设置页，默认显示“通知中心”页签。每条CompletionRecord独立成行；按未查看/已查看/已退休、结束时间、终态和工作区筛选，每页25条，上限50条。分页携带状态revision，变化时返回409并回第一页。列表只投影有界标题、时间、终态和身份元数据，不加载或发送对话正文。

点击行内“返回原对话”复用原有导航证据与有限确认，明确选用当前页面所属Client，避免多窗口时跳到另一个已绑定窗口。列表浏览不确认已查看；已退休目标不可打开。保留全部未查看记录与最近500条已查看/已退休历史；活动队列中的记录受保护，移出后再清理。历史裁剪保留去重区间和确认水位，不能复活旧结束。

## 静默规则

临时静默可选15、30、60、120分钟，结束时间保存为UTC毫秒，重启仍有效。定时静默可选本地起止时间及每周日期；默认每天22:00—08:00，但排程开关默认关闭。跨午夜按开始日期判断，起止相同为所选日期全天，日期全不选则不执行排程。

临时静默和排程取并集。取消临时静默不取消仍生效的排程。新增设置由原生configForms/Cordis Volatile存储，旧配置缺字段补默认值，false不会被覆盖。切换排程不重建结束订阅或计数Store。

静默进入时移除当前Profile的活动与排队卡片，不确认或退休完成记录，不影响其他已授权Profile。静默期间新结束仍持久化、计入去重数量并更新角标；只不入弹窗队列。解除后不回放旧静默记录。静默标记随记录保存，重连后也不能补弹。正常到点切换，时区/时钟变更最迟一分钟重算。

## 上下文

完成记录增加可选workspaceId/workspaceTitle、startedAt、durationMs、silenced。工作区仅取可信Workspace注册表及会话header的路径匹配，路径本身不保存或发送。任务历时由本进程单调时钟计算，包含等待，自动续跑保持同一开始边界，排队的新用户任务重置边界；启用中途未观测到开始时保持未知。

通知中心和前景卡片显示工作区及任务历时；当前又有任务运行时显示“新任务运行中”，并保留较早结束的时间，防止旧记录暗示新任务结束。运行状态只作实时展示，不参与结束事实或计数资格。

## 升级、协议与验证

保留schemaVersion=1的兼容扩展：新增字段均为可选，旧记录显示未知，不重置记录、确认水位或来源身份。0.2使用独立v2协调管道，原生互斥仍按实际应用分组，避免与未退出的旧Helper并写图标；升级时应退出所有启用本插件的DSH实例。

交付0.2.0预构建包、SHA256、源码绑定与新增测试。验证包括跨午夜/工作日/全天/临时重叠与重启、静默队列清理/计数保留/解除不补弹、分页与筛选不确认、历史保护及旧状态兼容、工作区和历时的元数据计算。本轮不修改真实Profile或代替用户执行完整真机验收。
