# 0.3.0 任务回执版

日期：2026-11-13。弹窗改为纸质回执视觉，保留0.2.0通知中心、静默、上下文、去重计数与导航边界。

## 外观与交互

暖白/炭灰实色纸面，浅齿底边，状态文字印章，独立标题/上下文/时间区，当前运行中的临时回执编号。打印线从左向右走完，悬停冻结；导航期间留卡、失败原位反馈。出纸160ms，完整绘制后开始预算；空队列退场最多110ms，仅显示无正文、不可点击的纸边。

支持明暗、高对比度、减少动画和系统文字放大，默认352×144 DIP。透明角、纸齿和阴影不接收正文点击。回执编号不写入业务记录，不代表待查看数，也不参与身份或去重。

## 检查与安装

开发检查包括业务回归、计时与输入竞态、独立对比度计算、WPF离屏图及几何一致性、x64编译和确切包解包加载。预构建包为artifacts/dsh-finish-reminder-0.3.0.tgz，配套SHA256及版本收据。

开发完成后直接备份并升级本机Desktop Profile，保留原配置、记录与启用状态；需要重启生效时明确提示，不强制终止真实任务。安装后的人工真机验收按开发文档RECEIPT-01至RECEIPT-14由用户执行。
